Getting an access token

Spreaker uses OAuth2 only — there is no API key and no permanent token, and refreshing one needs an app secret this app cannot safely hold. So the token is minted once, by hand:

1. Sign in at spreaker.com and enable Developer Tools in your account settings to register an app; note its Client ID and Client Secret.
2. Visit https://www.spreaker.com/oauth2/authorize?client_id=…&response_type=code&scope=basic&redirect_uri=… and approve it; the redirect carries a code.
3. Exchange it server-side: POST https://api.spreaker.com/oauth2/token with grant_type=authorization_code, your client id and secret, the same redirect_uri, and the code.
4. Paste the access_token from the reply above.

It is stored on this machine only. When it expires, uploads fail by name and you repeat steps 2–4.
