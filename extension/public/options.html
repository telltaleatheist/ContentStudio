ContentStudio Companion — Options

ContentStudio connection

The localhost port ContentStudio's ingest server listens on (default 43117). Shown on ContentStudio's Analytics page. No token is needed — the connection requires no configuration beyond the port.

Channels (from ContentStudio)

Channels are pulled live from ContentStudio — the app already has them registered, so there is nothing to configure here. Save the port above, then Refresh.

Visibility scheduler

A device key made on the scheduler's setup page, (Device keys). It is what the Visibility section of the Studio shelf uses to read and schedule visibility changes; that section talks to the scheduler directly and works with ContentStudio closed. Save an empty field to remove the key. Open Studio tabs pick up a new key on the shelf's refresh button.
