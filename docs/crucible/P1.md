## Deviations from the plan, and why

1. **The routing record carries `paused`.** The brief says `{selected, fastServer}` per Q14 and
   also asks for a Running/Paused switch. A switch needs somewhere to live, so the record is
   `{selected, fastServer, paused}`:
   - A paused server takes no new work, and its work **waits**. Nothing moves to another
     server, so #205 holds.
   - Pausing is not deselecting: the selection stays.
   - Readiness reports a paused selected server as `unreachable`, with the sentence "…is
     paused. AI work waits until it is set to Running". Queueing is allowed (the work waits)
     and an immediate call is refused.
   - A pre-ruling `{order, disabled}` file reads as its first running server, and its
     `disabled` list reads as paused.
2. **The probe has six outcomes, not five.** It has the plan's five (unreachable,
   not_a_crucible, wrong_token, version_mismatch, timeout), plus `refused` for any other named
   refusal in its own words, such as an orchestrator with no engine or an unknown name.
3. **Readiness departs from Briefcase in one rule.** "Crucible here but not in the list"
   offered Start whatever the local control said. It now offers:
   - Start when stopped or not answering;
   - add it when running;
   - install again when broken;
   - otherwise the control's own sentence.
4. **Briefcase's automatic start when AI work waits (`noteAiWaiting`) is not ported.** Nothing
   queues on Crucible until P3. Start is only ever the explicit door.
5. **The fake is Briefcase's, not BookForge's.** Plan §17 says copy BookForge's. Briefcase's is
   the newer port of it, with 1.0.25 nullability, pairing, decide and the 1.0.29 asr lineup.
6. **The adopted Mac server is registered as `crucible@owens-mac-studio`, not `mac`.**
   Auto-connect files a server under the name it calls itself, as Briefcase and BookForge do.
   The plan's `mac` was illustrative.
7. **The module JSON is not yet a PR to the crucible repo** (plan §3.4, §19 N10). It lives in
   `shared/crucible/` beside its `.toml`, generated by the tag's own generator, as Briefcase's
   does, until that PR lands.
8. **`MIN_CRUCIBLE` is 1.0.23**, as the plan says; Briefcase uses 1.0.24. Nothing in P1 needs
   `generate` or `decide`. The act is detected per server from `capability()`.
